How to Enable Location Access:
  • Google Chrome / Edge (Desktop): Click the padlock or settings icon to the left of the URL address bar → Set Location to Allow → Reload or click Retry.
  • Safari (iOS / iPhone): Open Settings → Safari → Location → Select Ask or Allow.
  • Android (Chrome): Tap the 3 dots → Settings → Site Settings → Location → Allow.
  • Ensure device location / GPS toggles are enabled in device settings.

  • Connect to the college campus Wi-Fi network for optimal positioning accuracy.
  • Make sure GPS / Location Services are switched ON in your device settings.
  • If using mobile data, move away from heavy concrete walls or near windows to obtain clean satellite reception.
  • Private / Incognito windows may block location by default – try using standard browser tabs.
